The matlab files contained herein are nearly unmodified from their original download version available at https://expage.github.io/calculator.html. The version used is 202403. The only modification is to the “make_consts_expage.m” file where the reference production rate was updated to account for the work here. Additionally 5 input text files were added: “input_TAMs.txt”, “input_ASE.txt”, “input_DML.txt”, “input_CRONUSA.txt”. These represent the input data used in the project and the “expage.m” script can be changed at line 37 to run any of these inputs as necessary.
